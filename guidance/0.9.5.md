# release-kit 0.9.5

- destinations: .release-kit/config.toml
- action: operator-step

## What changed

Every rk write to an existing `.release-kit/config.toml` keeps every byte outside the keys it changes. Before, an upgrade reset the whitespace in front of each template comment, so it undid the alignment that a formatter such as taplo gives the file.

## What to do

Nothing is required. A project that excluded `.release-kit/config.toml` from its formatter because rk undid the formatting can remove that exclusion, format the file once, and commit it.
