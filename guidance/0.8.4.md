## What changed

GitHub local integration now keeps the trunk's pull-request and strict required-check rules. The ruleset grants only the repository-administrator role a bypass for the deliberate direct trunk push, while the release App remains governed by the freshness check. The landed release workflows retain their retry job, safely encode configured workflow and check names, search every page of candidate requests, and run the push-side retry only after the request job succeeds.
