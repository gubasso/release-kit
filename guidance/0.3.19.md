# release-kit 0.3.19

- destinations: .envrc
- action: operator-step

## What changed

`rk devshell` became `rk self-depend`. The verb now serves every tool manager a target can obtain `rk` through, and no alias of the old name is kept: `rk devshell` is an unknown subcommand. No other landed destination changed in this release.

## What to do

`.envrc` is a seeded file. The landing never rewrites it, so a line it carries from an older release stays until the operator edits it. If `.envrc` carries `rk devshell sync --apply`, replace that line with `rk self-depend sync --apply`. If `.envrc` carries no such line, nothing changes.
