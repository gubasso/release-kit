# release-kit 0.9.11

- destinations: dist-workspace.toml, .github/workflows/release.yml
- action: operator-step

## What changed

The cargo-dist pin moves from 0.32.0 to 0.34.0, the latest release. The seed of `dist-workspace.toml` names 0.34.0 in `cargo-dist-version`. A landing never rewrites a seeded file, so a landed target keeps its own pin until the operator moves it. Until the next landing, `rk status` reports `STALE cargo-dist 0.32.0 landed, 0.34.0 in this binary`. For the configuration that the seed carries, the workflow that 0.34.0 generates differs from the 0.32.0 one only in the version of its installer URL.

## What to do

1. In `dist-workspace.toml`, set `cargo-dist-version = "0.34.0"`.
2. Run `dist generate` with dist 0.34.0. It rewrites `.github/workflows/release.yml`. Do not edit that file by hand.
3. Run `rk upgrade --apply`, then `rk status --check --target .`.
4. Commit `dist-workspace.toml`, `.github/workflows/release.yml`, and the upgrade together.
