# Comparison documents

This directory holds comparisons whose every verdict is a scenario that ran: a capability, the tools that compete on it, and what each tool did.

- [COMPARISON-release-tools-for-a-uv-project.md](./COMPARISON-release-tools-for-a-uv-project.md): which release tool bumps a uv project and keeps `uv.lock` consistent, how each computes the next version, which keeps one release request and on which forge, and whether `uv version` relocks without an index. It is the record the release engine's decision cites.
